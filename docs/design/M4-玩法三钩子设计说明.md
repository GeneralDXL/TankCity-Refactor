# M4 · 玩法三钩子设计说明

> **版本**：2026-10-04（随 M4 验收，分支 `feat/m4-gameplay-hooks`）
> **范围**：只覆盖 M4 交付的三条玩法钩子 —— 它们的**规则、数值、边界**与**明确不做的事**。
> 后续里程碑（M4.5 战斗与 AI / M5 网络统一 / M6 表现层）的机制不在本文范围内，见 §6「去向」。
> **数值的唯一来源是配置**（`assets/config/blocks.json`、`entities.json`）。本文引用的每个数值都取自那里；
> 改数值**不需要重编译**，而每条接线都有用例守着（§7）。

---

## 0. 一句话

把"地形"从**背景**变成**玩法**：**砖块是资源、钢材是镜子、森林是掩体、冰面是滑道**。

| 钩子 | 玩家的体验 |
|---|---|
| ① 地形即资源 | 打掉砖块会掉装备，而砖块同时是路障 ⇒ **"破哪面墙"本身成为决策** |
| ② 钢材反弹 | 弹性弹能在钢材与边界之间**来回弹 3 次** ⇒ 拐角处能打到看不见的敌人 |
| ③ 物块词条 | 森林让你**消失**、冰面让你**滑**、钢材必须用**穿甲弹**才破 ⇒ 同一张图里有多种打法 |

---

## 1. ① 地形即资源（砖块 → 掉落）

| 项 | 规则 |
|---|---|
| 触发 | 砖块（`brick`）被打掉的那一刻（耐久 **4**） |
| 掉落表 | 写在**物块侧**的 `blocks.drops`，按 `weight` 抽取：**医疗包 3 / 弹药夹 2 / 加油站 2** |
| 落点 | 砖块倒下的位置（道具留在地图上，开过去即可拾取） |
| 拾取 | 只有玩家可拾取；拾取后**立即生效** |
| 与"打通路径"的关系 | 同一件事：砖块既是资源也是障碍 |
| 现状 | ✅ 掉落与拾取已落地；⏳ **生成方式改版**（击杀概率掉落 / 定点刷新 / 特定敌怪必掉，三者共存，**替代随机刷新**）→ M4.5 |

---

## 2. ② 钢材反弹（弹性弹）

| 项 | 规则 |
|---|---|
| 弹种 | `bulletRicochet`（弹性弹）：伤害 1、可击破砖墙 |
| 能弹什么 | **钢材**与**地图边界**（`ricochet.bounceOn: ["steel","boundary"]`） |
| 弹几次 | 最多 **3** 次（`maxBounces: 3`），用尽后消失 |
| **不弹什么** | **砖墙**：命中即走正常伤害判定、**不反弹**（避免"既破墙又弹射"的叠加） |
| 反射几何 | 矩形-矩形相交 ⇒ 取**最小穿透轴**定为受击面 ⇒ 按该面做镜面反射。实现是**纯函数**（`game/world/reflect.*`），不依赖任何实体状态 |
| 对角命中的确定性 | 两个轴的穿透量相等时按**固定优先级**取面（详见 `reflect.h` 与 `ricochet_test` 的断言）—— 这是抖动与极限环的常见来源，所以写死并测试 |
| 与移动层的关系 | 子弹**不另写一套移动**：复用 M3 已验收的扫掠与"贴墙滑动"，只把方向换掉 |
| 已知特性（**非缺陷**） | 反弹子弹**可以命中开火者自己**并造成伤害。经确认"当成特性也蛮有意思"，**保持** |

## 3. ③ 物块词条

### 3.1 钢材：可破坏，但只认穿甲

| 项 | 规则 |
|---|---|
| 耐久 | **8**（砖是 4）—— 与"同级 4 下、越级 2 下"的数值律一致：穿甲弹（伤害 2）恰好 **4 下**破 |
| 门禁 | `requiredBulletTags: ["armorPiercing"]`：**不带该标签的子弹完全无效**（不是"伤害减半"） |
| 与 ② 的关系 | 钢材同时是**镜面**与**可破坏物** —— 先弹开还是先打穿，是玩家的选择 |

### 3.2 森林：减速 + 掩体（隐身）

| 项 | 规则 |
|---|---|
| 移速 | **×0.7** |
| 遮断 | `blocksSight: true` —— **不挡车、不挡弹、只挡视线** ⇒ **待在林子里 = 隐身** |
| 隐身判据 | 敌人的视线判定走 `blocksSight`（"子弹可通行、且不是森林"） |
| **距离无关** | 判据**包含目标所在格**，也包含**起终点同格**（贴身）⇒ 隐身在设计上的**任何距离**都成立，包括敌人压在你身上的那一格 |
| 不开火 + 不锁定 | 敌人看不见 ⇒ **不开火**；同时**炮口不再指向你**（改为跟随它自己的行进方向） |
| 双向性 | 判据是对称的：**站在林子里的敌人**同样看不见你（森林对谁都不传递视线） |
| 与"隐身道具"的区别 | **森林是地形**（待在林子里就隐身，**攻击不解除**）；**道具是限时的**（主动攻击立即解除，PVP 不渲染）→ M4.5。二者**独立共存** |
| 现状 | ✅ 上述全部落地；⏳ "看不见就**不寻路**" + 漫游状态 + 10 秒丢视野记忆 → **M4.5**（M4 只做到"不开火 + 不锁炮口"，敌人仍会朝你所在方向走） |

### 3.3 冰面：惯性（难控制，但可控）

| 项 | 规则 |
|---|---|
| 移速 | **×1.5**（更快，也更难收住） |
| 模型 | `movement.model: inertial`：坦克保留一个**速度向量**；有输入时它**朝目标速度按比例靠拢**，无输入时按**摩擦**衰减 |
| **参数配对律** | **`accelScale = 1 − frictionPerTick`**（即 0.05 = 1 − 0.95）。配对的含义是：**"按方向加速"与"松手滑行"是同一个速率**。不配对（例如 accel 给到 0.3）就会变成"转向比滑行灵敏得多" ⇒ 冰面**不再难控制** |
| 观感判据（可测） | 按住一个方向 3 帧只到目标速度的 **14%**；**换向 1 帧后旧方向分量仍保留 95%、速度仍为正** ⇒ 就是"先滑一段，才开始反向加速" |
| 踏冰继承 | 从陆地踏上冰面时**继承陆地速度**（不是硬掉到 0），再由摩擦与加速度把它拉到冰面目标速度。**站着进冰面**不会凭空多出速度 |
| 回陆地 | 陆地每帧覆写速度 ⇒ 冰上的惯性**不会**被带上岸 |
| 敌人同样适用 | **双方同规则**：敌人在冰上也难控。"冰上贴墙抽搐"由 **M4.5** 的状态机兜底（"目标不可达就放弃/漫游"），而不是给敌人开豁免 |

## 4. 数值表（唯一来源：`assets/config/blocks.json`）

| 物块 | 图层 | 耐久 | 破它需要 | 挡车 | 挡弹 | 挡视线 | 移速 | 移动模型 | 掉落 |
|---|---|---|---|---|---|---|---|---|---|
| `brick` | blocks | **4** | — | ✓ | ✓ | ✓ | ×1 | normal | 医疗包 3 / 弹药夹 2 / 加油站 2 |
| `steel` | blocks | **8** | `armorPiercing` | ✓ | ✓ | ✓ | ×1 | normal | — |
| `sea` | blocks | — | — | ✓ | ✗ | ✗ | ×1 | normal | — |
| `forest` | overlay | — | — | ✗ | ✗ | **✓** | **×0.7** | normal | — |
| `ice` | ground | — | — | ✗ | ✗ | ✗ | **×1.5** | **inertial**（friction 0.95 / accel 0.05） | — |

> 图层与渲染顺序见 `assets/config/layers.json`；`sea` 的口径是"**挡车不挡弹**"，
> 因此敌人可以**隔着海**朝你开火 —— 这是有意的："看得见，但我得绕过去"。

`assets/levels/level_15.json`「**三钩子试验场**」—— 一张图内同时具备：

- **钢材通道**（② 反弹 + ③ 穿甲门禁）

- **冰面**（③ 惯性）

**纯 JSON**，加关卡不需要改任何代码 —— 这条能力由 M3 建立（4 张 tile 图），M4 继续沿用。

## 6. 明确不做（本里程碑的边界与去向）

| 不做 | 去向 |
|---|---|
| 经济系统（货币 / 材料点） | **不做** —— 计划书自己点名的"过度设计"，定为硬边界 |
| 弹药栈（弹夹制）、5 种坦克类型、8 种道具、护盾、掉落的生成方式改版 | **M4.5 · 战斗与 AI** |
| 追踪弹（`homing`） | **M4.5** —— 它需要"目标列表"，与 AI 状态机同批改完才不必打临时补丁 |
| 敌人 AI 状态机（漫游 / 10 秒丢视野 / 看不见就不寻路 / 丢失处切线） | **M4.5** |
| 反弹与掉落音效、`damageVisual` 受损表现、森林透明间隙贴图、棋盘背景 | **M6 表现层** |
| 资源加密、数据库 | **不做**（决策与理由见项目内部的决策台账） |
